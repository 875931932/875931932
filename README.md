## 代表项目

### PaperPact · AI 命题系统

**个人开发**，面向高校教师，提供资料问答、知识卡构建、试卷生成与审核导出。

- 基于 LangChain 实现关键词与向量混合检索，组织带来源的知识卡。
- 使用 LangGraph 编排按考点分批生成、格式校验和失败局部重试。
- 为 AI 助手接入 16 个工具，按工具配置区分自动执行与教师确认。
- 获 2026 全球人工智能算法精英大赛省赛二等奖，获奖证书待发放。

技术栈：Python / FastAPI / LangChain / LangGraph / RAG。
